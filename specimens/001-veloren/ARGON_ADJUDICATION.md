## Cross-cutting corrections
- `CachedSpatialGrid` uses two `HashMap<Vec2<i32>, Vec<Entity>>` stores with radius tiering, not an intrusive `Int32Array` grid (MEC-001).
- `in_circle_aabr` yields candidates from a bounding rectangle, not exact-circle set membership; the independent experiment adds exact-circle filtering intentionally.
- `SIMULATED_TICK_SKIP` is **10** at the pinned revision (`rtsim/src/rule/npc_ai/mod.rs` line 97), not Argon’s proposed EXP-002 example of 16.
- The official mirror HEAD was recorded as a commit, not inferred from Rustdoc crate version 0.18.0. The GitLab API provided an older cached head.
- Estimated code sizes, zero-allocation claims, frame rates, crossover thresholds and Apple Silicon performance are not observed facts.
- Source signatures alone do not prove runtime behavior. The matrix does not promote 22 patterns.
- MRs and code from other revisions are not assumed merged unless the snapshot implementation demonstrates the claimed effect.
- No legal conclusion is asserted beyond the confirmed root license and the need for file-level review.

## Experiment feasibility
Argon full matrix has 4 entity counts × 4 movement rates × 3 query levels × 3 distributions × 3 radii × 10 processes × 2,000 measured ticks = 8,640,000 measured tick trials **per algorithm**. Its naive brute-force baseline would require roughly 5.81×10^15 candidate-distance checks (excluding warmup) if every dimension is crossed. This is not an appropriate first pilot.

Decision: run EXP-001 only as a bounded TypeScript pilot; defer remaining claims rather than filling gaps with speculation.
